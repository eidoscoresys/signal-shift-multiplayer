# Licensing options — decision pending

No project-wide open-source license has been assigned. package.json uses UNLICENSED to record that decision; it is not an MIT/Apache/GPL grant. Public visibility and creator credit are separate from licensing. Dependencies keep their own terms.

| Option | Practical reuse implications |
| --- | --- |
| MIT | Broad use, modification and redistribution, including commercial/closed-source derivatives, while retaining required copyright and license notices. It does not require prominent in-game creator credit. |
| Apache-2.0 | Broad reuse with notice requirements and an express contributor patent license, including termination provisions. It does not grant trademark rights or require a derivative to remain open source. |
| GPL-3.0 | Copyleft obligations apply when covered software/derivatives are conveyed: recipients receive the corresponding source and covered derivative licensing remains GPL-compatible. Operating a modified server by itself is different from distributing it. |
| AGPL-3.0 | Adds network-use source-offer obligations for modified covered software interacting with users remotely; relevant to a hosted multiplayer backend. |
| No selected license | No general project reuse permission is granted merely by publishing source. GitHub's platform terms and applicable legal exceptions still apply. This is source-visible, not a claim of open-source licensing. |

Creator attribution in the README, credits page and case study accurately records Quindel Logan's contributions under any of these choices. Standard permissive licenses generally require retaining legal notices, not a prominent in-game credit or endorsement. Adding special branding/credit restrictions changes the licensing arrangement and should be considered separately; do not label custom restrictions as standard MIT/Apache terms.

Code and original artwork may use different approved licenses. Do not assume permission to relicense third-party dependencies, logos or assets. An AI-assisted process also does not by itself establish identical copyright protection for every generated element in every jurisdiction. This comparison does not resolve ownership or jurisdiction-specific legal questions.

No LICENSE file will be added and no permissive grant will be applied until Quindel selects terms. After approval, use the complete official license text, accurately identify covered material, retain dependency notices and record the decision in the release notes.
