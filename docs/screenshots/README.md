# Portfolio screenshot provenance

The four PNGs in this folder are copies of actual, unaltered browser gameplay captures from automated rc.2 acceptance sessions:

- power-routing.png — original docs/engineer-mobile.png.
- thermal-balance.png — original docs/thermal-engineer-mobile.png.
- final-override.png — original docs/finale-callouts-mobile.png.
- victory.png — original docs/mission-victory.png.

They use fictional automated-test callsigns. They contain no authentication material, cookies, browser chrome or local filesystem paths. The room identifiers are ordinary test-room codes, not session credentials. These captures are evidence of rendered gameplay, not proof of physical-device testing or a new human usability study.

Raw captures and traces remain ignored; only these reviewed portfolio images are intended for source publication. The original SVG competition cover is in assets/.
